# 系列脚本 · 打工人《35 岁被优化的中层》（5 集追更）

> 这是把 [`实战样例`](实战样例-打工人职业副本.md) 选题 #3 做成**系列追更**的范例——用 [`08`](08-人生副本Universe.md) 的"系列化世界观"机制，把一个选题拆成 5 集，集集留钩子，逼出"想看下一集 → 关注"。
> 人设沿用「职场副本·系统」，包装沿用工牌/考勤终端风（见 [`实战样例`](实战样例-打工人职业副本.md) 第六节）。

---

## 系列设定

- **主角**：你，37 岁，某公司中层，工龄 12 年，房贷 + 二胎 + 房车皆有。
- **主线**：被优化 → 求职碰壁 → 自我重估 → 转机 → 上岸（但不是回到原点）。
- **追更逻辑**：每集是独立 60 秒短视频，但结尾留"下一集"悬念；开头用一句"上集说到……"接续，方便新观众入坑、老观众追更。
- **发布节奏**：隔日更，5 集打完一个完整弧光；数据好就给主角开"新副本"（如《37 岁转行的人》）。

---

## EP.01 · 被优化那天

```
（①Hook）人生副本·职场篇，第 37 关。本关名称：被优化。开局提示——你以为最稳的一关，往往最致命。
（②身份）系统提示：你工龄 12 年，职级 P8，是同事眼里"熬出头"的人。你的负债栏写着：房贷、车贷、两个孩子。
（③成长回放）你把最好的 12 年点满在了这家公司：救过项目、带过新人、加过无数个班。你以为忠诚是一种装备。
（⑦随机事件）⚠ 随机事件触发：周一上午，HR 约你"聊一聊"。一份《协议解除》推到你面前，理由是"组织优化"。
（情绪）你没吵，签了字。走出大楼那一刻，阳光很好，你却第一次发现——这座城市，没有一个工位是真正属于你的。
（⑨钩子）系统提示：主线任务已失效，你被强制丢回"自由市场"。
下一关，比被裁更难：一个 37 岁的人，重新找工作。你觉得他几个月能上岸？评论区押一押，下集揭晓第一道坎。
```

## EP.02 · 投出去的简历，石沉大海

```
（①Hook 接续）上集说到，37 岁的你被优化了。你以为凭 12 年经验，找工作不难——这一关，啪啪打脸。
（④过程）你更新了简历，投了 80 份。前 50 份，已读不回。你第一次知道，有些公司的筛选第一条是"年龄≤35"。
（⑤选择）【选择】A. 降薪求稳，什么都接；B. 死扛，只投对口的好岗位。供着房贷的你，选了 A。
（⑦事件）⚠ 你去面试一个比原来低两级的岗位，面试官比你小 8 岁，问你："你这个年纪，还能加班吗？还带得动吗？"
（情绪）回家路上你坐在车里，没有开车库的灯，坐了很久。你不是不能扛，你是第一次怀疑：是不是我真的没用了？
（⑨钩子）系统提示：你的"自信值"跌到谷底，触发隐藏剧情——"自我重估"。
下集，你会发现自己手里其实握着一张一直没打出去的牌。是什么？下集见。
```

## EP.03 · 最难的一关：给自己重新估值

```
（①Hook 接续）上集你跌到谷底。这一集，是整个副本的转折点——你终于做对了一件事。
（④顿悟）你不再海投，而是拿出一张纸，写下三栏：我真正会的、我认识的人、市场缺的。
（认知）你发现：你以为的资产是"职级"，其实早就清零了；你真正的资产，是 12 年攒下的**行业经验、人脉和解决问题的能力**——这些没人能优化掉。
（⑤选择）【选择】A. 继续找一份"打工"；B. 把自己当成一个"产品"重新定位。这次，你选了 B。
（行动）你删掉了"求一份工作"的心态，开始主动约老同事、老客户喝茶，不为求职，只为"让对的人知道我现在有空"。
（⑨钩子）系统提示：你点亮了新技能——"把人脉变成机会"。
三天后，一个你几乎忘了的旧同事，给你打了一个电话。下集，转机来了。
```

## EP.04 · 一个旧同事的电话

```
（①Hook 接续）上集你开始重新经营人脉。这一集，那张牌打出去了。
（⑦随机事件）⚠ 随机事件：五年前你帮过的一个下属，如今自己创业，缺一个懂行的"老法师"压阵。他第一个想到了你。
（⑤选择）【选择】A. 要一份稳定高薪，做回打工人；B. 要一点股份 + 基础工资，赌一把。
（权衡）37 岁、上有老下有小的你，本该选 A。但你想起前两关学到的事：最稳的一关，往往最致命。
（决定）你和他谈了三个晚上，选了 B——但你给自己留了 6 个月生活费的"复活甲"，没有 all in。
（⑨钩子）系统提示：你做出了 12 年来第一个"为自己"的选择。
这个选择，3 年后会给你什么样的结算？下集，大结局，三种可能的人生。
```

## EP.05 · 上岸，但不是回到原点（多结局）

```
（①Hook 接续）大结局。37 岁被优化的你，3 年后过成了什么样？系统给出了三种结算。

（结局一·普通结局 · 达成率 58%）
小公司没做大，但稳住了。你拿着比原来略低的钱，却找回了对生活的掌控感。
【结算】财富★★★ 健康★★★★ 家庭★★★★ 快乐★★★★ 成就★★★
旁白：原来"上岸"不是回到大厂，是不再怕被任何一家公司决定你的人生。

（结局二·隐藏结局 · 达成率 9%）
公司被收购，你的小股份兑现，你拿到了打工 12 年都没攒下的一笔钱。
旁白：你没赢在选得多，你赢在被优化那天，没有把自己也一起优化掉。

（结局三·真结局 · 达成率 ?%）
你把这 3 年的经历讲出来，意外帮到了很多同样 35+ 的人——你成了那个"过来人"。
旁白：有些副本，通关的方式不是赢，是把走过的坑，变成别人的地图。

（⑨金句 + 互动）
系统总结：35 岁不是被淘汰的年纪，是这张地图刷新了的年纪。
你身边有正在闯这一关的人吗？把这 5 集转给 TA。
下一个你想看谁的副本？评论区点单。
```

## 系列运营要点（08 章）

- **每集结尾的钩子**是追更命门：EP.01 抛问题、EP.02–04 留"下集揭晓"、EP.05 给多结局制造"二刷找隐藏结局"。
- **置顶引导**：EP.01 置顶"押他几个月上岸"；EP.05 置顶"你押对了吗"，形成首尾呼应。
- **合集功能**：把 5 集做成抖音"合集"，提升连看完播和关注转化。
- **数据好就续作**：主角可以继续开新副本（转行/创业/再就业），把"一个人物"做成"可追的连续剧"。
