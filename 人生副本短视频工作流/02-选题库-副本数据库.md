# 02 · 选题库 · 副本数据库（STEP 1）

> **选题占 80% 的爆款概率。不要随机想题，建数据库、按需取用。**
> 本章给你：① 五大类现成副本清单（200+ 条）② 把库扩到 1000 的组合公式 ③ 选题打分筛选法 ④ 黑暗类合规红线。

---

## 一、五大类副本清单（直接抄）

### 第 1 类：职业副本（最好起量，新手从这里开始）
> 逻辑：人人都对"别人的职业到底什么体验"好奇，代入感最强，且永远做不完。

```
外卖员 / 快递员 / 网约车司机 / 程序员 / 产品经理 / 交易员 / 投行分析师
医生 / 护士 / 律师 / 老师 / 公务员 / 警察 / 消防员 / 军人
主播 / 网红 / 演员 / 明星 / 经纪人 / 编剧 / 自由职业者
保安 / 保洁 / 工厂流水线工人 / 建筑工 / 矿工 / 农民 / 渔民
老板 / 创业者 / 销售 / 中介 / 个体户 / 富二代 / 拆迁户
厨师 / 理发师 / 健身教练 / 殡葬师 / 宠物医生 / 飞行员 / 船员
```

### 第 2 类：黑暗副本（传播最高 ⚠️ 务必合规，见文末红线）
> 逻辑：禁忌感 + 警示性带来高转发。**只做警示/反诈/剧情体验，绝不教方法、不美化、不引流。**

```
赌徒（戒赌警示）/ 网贷上岸者 / 高利贷受害者 / 被传销洗脑者（脱困）
诈骗园区幸存者（反诈）/ 电信诈骗受害者视角 / 杀猪盘受害者（反诈）
黑中介踩坑者 / 碰瓷者的下场 / 刷单兼职受骗者 / 虚拟币爆仓者
```
> 全部以"我差点……幸好……"或"系统警告：此路线 99% 通向 BAD END"的**警示框架**呈现。

### 第 3 类：时代副本（情怀 + 共鸣，中老年也爱看）
> 逻辑：每个时代都有"如果我生在那时会怎样"的遐想，自带怀旧与时代红利讨论。

```
90 年代国营工厂 / 下海经商潮 / 第一批个体户 / 第一代农民工
2000 年代网吧少年 / 第一批淘宝店主 / 山寨机时代 / 城中村房东
2010 年代互联网创业 / 房地产黄金时代 / 比特币早期玩家 / 微商时代
公众号红利期 / 短视频元年博主 / 直播电商爆发期
AI 时代（2023 后）的创业者 / 第一批 AI 副业玩家
```

### 第 4 类：历史副本（差异化强，竞争少，文化感高级）
> 逻辑：把历史身份当副本，新鲜感强、容易做出"独一份"的辨识度。

```
秦朝戍边士兵 / 汉代戍卒 / 科举考生（寒窗到金榜）/ 落第秀才
锦衣卫 / 太监 / 御医 / 翰林 / 县令 / 师爷 / 镖师
古代海商 / 晋商徽商 / 茶马古道马帮 / 海盗 / 倭乱年代的渔民
战国说客 / 三国谋士 / 唐代胡商 / 宋代汴京商贩 / 明代倭患沿海百姓
末代皇族 / 民国报童 / 民国大学生 / 抗战时期的普通人
```

### 第 5 类：未来副本（科幻爽 + 话题性，吸引年轻人）
> 逻辑：满足对未来的想象与焦虑，天然引发评论（"这是好事还是坏事"）。

```
AI 公司的人类老板 / 被 AI 取代的白领 / 人机协作的打工人
家用机器人（以机器人视角过一生）/ 仿生人 / 觉醒的 AI
火星第一代移民 / 太空矿工 / 月球基地居民 / 星际难民
数字永生者（意识上传）/ 脑机接口玩家 / 记忆可买卖的世界
克隆人 / 基因定制婴儿 / 赛博格 / 元宇宙原住民 / 末日幸存者
```

## 二、把库扩到 1000 的组合公式（工业化关键）

不要靠灵感，用**乘法**批量生成。一个副本 = 四个变量相乘：

```
副本选题 =  ①身份  ×  ②时代/地点  ×  ③核心变量(难度/转折)  ×  ④视角
```

| ①身份 | ②时代/地点 | ③核心变量 | ④视角 |
|-------|-----------|----------|-------|
| 程序员 | 90 年代 / 现在 / 2050 | 出身贫寒 / 含金钥匙 / 天降横祸 | 第一人称 |
| 外卖员 | 一线城市 / 县城 / 火星 | 中途转行 / 一条路走到黑 | 系统播报 |
| 科举考生 | 大唐 / 大明 / 架空 | 屡败屡战 / 一举成名 | 旁观者 |
| 医生 | 战乱年代 / AI 时代 | 救人无数自己崩溃 / 医闹 | 上帝视角 |

**示例**：`程序员 × 2050 AI 时代 × 被自己写的 AI 取代 × 第一人称` → 《我是 2050 年最后一个程序员》。
**示例**：`科举考生 × 大明 × 考到 50 岁才中 × 旁观者` → 《他考了 30 年，中举那天却……》。

> 4 个变量各列 10–30 个选项，相乘就是成百上千个选题。**每周花 30 分钟扩库，永远不缺题。**

### 选题灵感的 5 个挖掘渠道
1. **评论区**：自己和对标号视频下，观众喊"求做 XX"的，直接做。
2. **热搜/热点**：把当下热点人物/事件包装成副本（如某职业上热搜 → 做该职业副本）。
3. **百度/知乎搜"XX 是一种怎样的体验"**：高赞回答就是现成剧本素材。
4. **对标号反推**：把对标号的爆款选题，换一个人群/时代/视角重做（合规改编，非搬运）。
5. **自己的人生**：你或身边人真实经历过的副本，细节最真、最容易爆。

## 三、选题打分筛选法（决定先做哪条）

每个选题按下面 5 项各打 1–2 分，**总分 ≥ 7 分**的优先做：

| 维度 | 问自己 | 满分 |
|------|--------|-----|
| 代入感 | 观众容易把自己代入吗？ | 2 |
| 情绪强度 | 能激起强情绪（唏嘘/不服/警醒/爽）吗？ | 2 |
| 转发动机 | 观众会想转给某个特定的人吗？ | 2 |
| 反差/转折 | 有没有意料之外的转折或结局？ | 2 |
| 合规安全 | 不踩红线、不擦边、不教坏吗？ | 2（一票否决） |

> 合规这项是**一票否决**：打 0 分直接弃用，不管其他多高。

## 四、⚠️ 黑暗副本合规红线（必读，保号保命）

黑暗类传播最高，但**也最容易被限流、封号甚至违法**。死守以下红线：

**绝对不做**：
- ❌ 教任何违法/灰产的**具体方法、话术、流程**（赌、骗、贷、传销等）。
- ❌ 美化、炫耀违法所得，或暗示"来钱快值得"。
- ❌ 为任何违法平台/项目**引流、导流、留联系方式**。
- ❌ 渲染血腥、暴力、自残、极端负面诱导。

**正确姿势**：
- ✅ 以**受害者视角 + 警示结局**呈现："我以为能赚快钱，结果家破人亡"。
- ✅ 落点放在**反诈、避坑、上岸**："系统警告：此副本 99% 通向 BAD END，建议立即退出。"
- ✅ 结尾给**求助/正规出路**信息（如反诈提示），传递正向价值。

> 一句话：黑暗副本做的是"**劝退片**"，不是"教学片"。平台规则和法律都站在劝退这边。
