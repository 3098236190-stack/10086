# 人生副本 · 短视频工作流（AI 工业化版）

> 一套可复制、可批量、可长期运营的「人生副本」赛道短视频生产 SOP。
> 核心回答两个问题：**它为什么能爆** + **怎么搭一套可复制的工作流**。

---

## 一句话讲清这个赛道

把**一段人生**当成一个**游戏副本**来通关解说——
出身是「开局」，职业是「职业副本」，高考/求职/婚姻是「关卡」，裁员/疾病/机遇是「随机事件」，
最后给出「人生评分」。用第一人称沉浸式叙事 + 游戏化 UI 包装，让观众在 60 秒里**体验另一种人生**。

它能爆的根本：**模拟人生是顶级母题**（《人生重开模拟器》曾 3 天 20 亿访问量），
而 AI 把"做一条这样的视频"的成本从几千元降到几块钱——**需求一直在，供给端刚被 AI 打开**。
完整分析见 👉 [`00-为什么能爆.md`](00-为什么能爆.md)（这是本工作流的灵魂章节）。

赛道时间窗：2026 年 6 月，抖音搜【人生副本】已出现大量模仿号，**红利期开始但远未饱和**，且大多数模仿号停留在"AI 配图 + 第一人称念稿"的初级形态——**升级空间巨大**（见 [`08`](08-人生副本Universe.md)）。

## 标准生产流水线（一条视频）

```
①选题        ②写剧本       ③配音        ④出画面          ⑤合成        ⑥发布
副本数据库 → 套五幕模板 → AI 配音 → 文生图→图生视频 → 剪映+UI包装 → SEO埋词
（STEP1）    （STEP2+3）   （STEP4）   （STEP4+5）      （STEP6）     （发布运营）
```

熟练后单条 **30–60 分钟**；批量模式可「一天产一周的量」（见 [`09`](09-7天上手SOP与批量排期.md)）。

## 核心心法（先记住这 6 条）

1. **形式 > 数量**：好形式能让 9 条视频做到几万粉（参考"人生体验服"），别一上来追日更。
2. **前 3 秒定生死**：钩子勾不住人，后面全白搭。每条先磨"载入提示"和第一句。
3. **认知爽感 + 情绪共鸣，二选一必须有**：观众点赞要么"被说中"，要么"原来如此"。
4. **包装一致 = 品牌**：固定 UI（Loading / Lv / HP / 评分面板）+ 固定开场，让人一眼认出你。
5. **别做纯模仿**：选一个**细分人群/独特副本类型**切入，差异化在 [`01`](01-赛道分析与账号定位.md)。
6. **合规第一**：黑暗类副本（赌徒、诈骗园区等）一律以**警示/反诈/剧情体验**角度做，不教方法、不美化（见 [`02`](02-选题库-副本数据库.md) 合规红线）。
