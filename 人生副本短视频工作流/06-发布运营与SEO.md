# 06 · 发布运营与 SEO

> 视频做得好只是一半，发得对是另一半。这一章解决：**怎么被搜到、被推到、被互动起来。**

---

## 一、抖音 SEO：让"搜人生副本"的人搜到你

赛道有大量搜索流量（用户主动搜【人生副本】），**把关键词埋进 4 个位置**：

```
1. 标题/文案：必含"人生副本" + 副本名（如"人生副本：外卖员的一生"）
2. 话题标签：#人生副本 #人生模拟器 + 垂直词
3. 封面文字：大字直接写"人生副本 · ____的一生"
4. 视频口播/字幕：开场就说出"人生副本"四个字（语音也会被识别为搜索词）
```

> 搜索流量是"长尾复利"——一条视频能被搜半年。**每条都埋词，不要嫌烦。**

### 话题标签矩阵（每条选 5–8 个）
```
核心词：#人生副本 #人生模拟器 #人生重开
形式词：#AI视频 #第一人称 #沉浸式体验
情绪词：#人生感悟 #扎心 #治愈 #逆袭
人群词：#打工人 #职场 #小镇青年（按你的人群定位选）
蹭热词：当下相关热点话题（谨慎、相关才用）
```

## 二、发布时间与频率

| 项目 | 建议 |
|------|------|
| **黄金时段** | 中午 11:30–13:00、晚上 18:00–22:00（晚高峰最佳） |
| **频率** | 起号期日更或隔日更（喂数据）；稳定后保证"系列可追更"的节奏 |
| **测试** | 同一选题不同钩子/封面，发不同时段做 A/B 对比 |
| **删低质** | 起号期一条数据极差（完播<10%）可删除重发，避免拉低账号权重 |

> 但记住 [`01`](01-赛道分析与账号定位.md) 的洞察：**形式 > 数量**。宁可少而精，不要为日更牺牲质量。

## 三、冷启动：前 5 条 + 前 500 粉怎么破

新号没权重，靠这几招过初始流量池：

1. **前 5 条是"定位锚"**：必须同一人设、同一包装、同一类副本——让系统给你打准标签，也让进来的人知道"关注你能持续看到什么"。
2. **死磕 5 秒完播**：前 5 条把钩子打磨到极致，5 秒完播率 > 50% 才有加推。
3. **发布后 1 小时是黄金期**：发完盯着评论区，**第一时间回复每条评论**（拉互动权重）。
4. **自己埋第一条神评论**：发布后用小号/自己置顶一条引导性评论（见下）。
5. **不要买量、不要互赞群**：会污染账号标签，得不偿失。

---

## 四、评论区运营（被严重低估的涨粉/完播杠杆）

评论区是第二个内容场，运营好能二次拉升推荐：

- **置顶引导评论**：每条发完，自己置顶一条钩子评论，例：
  ```
  · "选 A 的扣 1，选 B 的扣 2，看看大家都怎么选👇"
  · "想看下一个副本是什么？点赞最高的我下条就做。"
  · "这局我给打 60 分，你们呢？"
  ```
- **回复即追问**：别人评论后，用反问把话题续下去（提升评论层数和停留）。
- **从评论里挖选题**：观众喊"求做 XX"——直接做，并 @ 他，形成"你点单我来做"的社区感。
- **挑动良性站队**：A/B 选择、不同结局，天然引发讨论，别怕有分歧（有争论=有互动）。

> 评论区里"点单—产出—@回应"的循环，是把看客变粉丝的关键，也是通往 [`08`](08-人生副本Universe.md) 互动机制的起点。

## 五、完播率优化清单（算法的命门指标）

```
□ 前 3 秒有钩子（载入条 + 悬念句）
□ 没有"大家好我是……"这种废开场
□ 节奏紧、无废镜头，越往后越快
□ 结局前留悬念/停顿，吊住最后 5 秒
□ 时长别贪长（先做 45–60s，完播不行就压短）
□ 字幕清晰、关键词高亮（静音也能看懂）
```

---

## 六、数据不好时的排查顺序

按这个顺序找问题，**从前往后查**（越靠前影响越大）：

```
完播率低（<15%）   → 钩子/节奏问题 → 改前 3 秒、压时长
完播高但点赞低     → 缺情绪/认知爽点 → 改结尾金句和高潮
点赞高但转发低     → 缺"转给某人"的动机 → 加人群指向性
互动低（评论少）   → 没留互动钩子 → 结尾加投票/提问
涨粉低（数据都还行）→ 缺系列感/人设 → 强化固定包装 + 可追更（08）
```
