# 05 · 固定包装与视听规范（STEP 6）

> **所有视频保持一致的包装 = 品牌认知。** 观众划到第 3 秒还没看脸，光看 UI 就知道"是这个号"。
> 这是护城河的第一层（见 [`00`](00-为什么能爆.md) 第五节）。包装做一次，复用一辈子。

---

## 一、固定 UI 元素库（每条都用，位置固定）

把下面这套游戏化 UI 做成**剪映/PS 模板**，每条视频直接套：

| 元素 | 文案/形态 | 出现时机 | 作用 |
|------|----------|---------|------|
| **载入条** | `人生副本 · 正在载入…… LOADING ▓▓▓░ 70%` | 开场 0–2s | 钩子 + 仪式感 |
| **副本标题** | `《______ 的一生》` | 开场 | 点题 |
| **身份卡** | `身份：______  开局难度：★★★☆☆` | 身份介绍段 | 信息 + 代入 |
| **等级条** | `Lv.1 → Lv.2 → Lv.3 …` | 成长段 | 表现成长 |
| **属性面板** | `HP 生命 / Money 财富 / Age 年龄 / Skill 技能` | 全程角标 | 游戏感 |
| **任务提示** | `Mission：______`（主线/支线） | 选择段 | 推进剧情 |
| **选择弹窗** | `【选择】A. ____  B. ____` | 抉择点 | 互动 + 悬念 |
| **随机事件** | `⚠ 随机事件触发！______` | 高潮段 | 制造意外 |
| **结算面板** | `ENDING + 五维评分（财富/健康/家庭/快乐/成就）` | 结尾 | 收束 + 讨论 |

**统一英文标签（视觉签名）**：`LIFE INSTANCE / LOADING / Lv / HP / MONEY / AGE / SKILL / MISSION / ENDING`。

> 这套标签英文化，是为了游戏感和辨识度——长期固定不变，就是你的"视觉签名档"。

---

## 二、选一套视觉风格（差异化关键，长期固定一套）

别人都用"赛博蓝光 HUD"，你可以选一套**没人用的**来区隔（见 [`01`](01-赛道分析与账号定位.md) 路线 C）：

| 风格包 | 配色 | 适合副本类型 | 记忆点 |
|--------|------|------------|--------|
| **赛博终端风**（默认） | 黑底 + 蓝/青全息光 | 职业、未来、AI | 科技 HUD、扫描线 |
| **黑金高级风** | 纯黑 + 金色描边 | 财富、逆袭、商战 | 极简、高级、有钱感 |
| **水墨国风** | 宣纸米色 + 墨黑朱红 | 历史、科举、古代 | 卷轴、印章、毛笔字 |
| **像素游戏风** | 8-bit 彩色 | 校园、怀旧、时代 | 复古游戏机感 |
| **档案监控风** | 暗灰 + 警示红/绿 | 黑暗、警示、悬疑 | 监控框、档案袋、打码 |

> 选定一套就**别换**。同一套配色 + 同一组风格词（见 [`04`](04-AI制作流水线与Prompt.md)）贯穿所有视频。

## 三、字幕规范（直接吃完播率）

字幕是观众的"第二条旁白"，60% 的人静音看，字幕没做好等于白做：

```
字体：粗黑体 / 思源黑体 Bold（清晰、有力）
字号：大（占屏宽 ~80%），手机上一眼能读
位置：屏幕下方 1/4 处，固定不动
描边：黑色描边 + 轻微阴影（保证任何背景都看清）
高亮：关键词变色（如主色调蓝/金），每句突出 1–2 个词
节奏：一句一行，跟着配音逐句出，不要整段堆上去
```

> 关键词高亮 = 引导视线 + 强化记忆点，是这套内容的"标配动作"。

---

## 四、音频规范（听觉签名）

声音的一致性和画面一样重要：

| 音频层 | 选择 | 说明 |
|--------|------|------|
| **配音音色** | 固定 1 个（沉稳男声 / 电子机械音 / 知性女声） | 你的听觉签名，长期不换 |
| **开场音效** | 固定 1 个"系统启动/载入"音 | 听到就知道是你（强记忆点） |
| **BGM** | 按基调备 3 类：史诗燃 / 悬疑暗 / 治愈暖 | 音量压在人声下方，别盖住旁白 |
| **节点音效** | 升级"叮"、选择"滴"、结算"通关音" | 给 UI 元素配音效，游戏感拉满 |
| **结尾留白** | 结局前 0.5s 停顿 / 黑屏 | 制造期待，提升结尾完播 |

> **开场音效 + 固定音色 = 听觉签名**。很多人是"听到那个音"才认出账号的。

## 五、封面规范（影响推荐页点击率）

```
· 主图：最有冲击力的一帧（结局/高潮画面）
· 大字标题：4–8 字，埋词"人生副本/XX的一生"（见 SEO，06）
· 统一模板：固定字体、固定位置、固定角标（如左上角永远是"人生副本 EP.xx"）
· 系列编号：标上"EP.01 / 第3局"，强化"可追更"暗示
```

## 六、"固定包装"检查清单（每条发布前过一遍）

```
□ 开场有载入条 + 副本标题了吗？
□ 属性面板/等级条出现了吗？
□ 用的是我固定的那套配色和风格词吗？
□ 字幕字体/位置/高亮统一了吗？
□ 开场音效 + 配音音色是固定那一套吗？
□ 结尾有结算面板 + ENDING 了吗？
□ 封面是统一模板 + 系列编号吗？
```

> 全部打勾 → 这条视频"一眼是你"。这就是把"模板"做成"品牌"的全部秘密。
