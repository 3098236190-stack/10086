# 模板 · 五幕剧本（空白版）

> 每条视频复制一份填空。对应九段式公式，详见 [`../03-视频公式与五幕剧本.md`](../03-视频公式与五幕剧本.md)。
> 目标时长 45–60 秒，每段一句话、口语化、有节奏。

---

```
副本名：《______ 的一生》    人群/基调：______    人设：______


【第一幕 · 副本开启】（0–8s，①Hook ②身份）
①Hook：正在载入人生副本……本次随机身份：______，开局难度：______。
②身份：系统提示：______（一句话点出最大悬念或反差）


【第二幕 · 出生与成长】（8–25s，③出生 ④成长）
③出生：你出生在 ______（年代/地点/家境），父母 ______，初始天赋：______。
④成长：你一路 ______，直到站在第一个岔路口。
（UI：Lv.1 → Lv.2）


【第三幕 · 第一次选择】（25–35s，⑤）
⑤选择 1：
   A. ______（稳妥）
   B. ______（冒险）
   你选了 ____。


【第四幕 · 随机事件与转折】（35–55s，⑥⑦）
⑦随机事件：🎲 ______（机遇/灾难/贵人/被骗）
⑥选择 2：A. ______  B. ______ —— 你选了 ____，没有回头路。


【第五幕 · 结局与评分】（55–70s，⑧⑨）
⑧结算：
   财富 ★____  健康 ★____  家庭 ★____  快乐 ★____  成就 ★____
   ENDING：______（普通/隐藏/BAD END/真结局，可标达成率）
⑨金句：______（能当标题的一句话）
   互动钩子：______（投票/提问/求评分，决定下集走向）
```

---

## 填写自检（写完过一遍）

```
□ Hook 能在 5 秒内勾住人吗？
□ 命中"代入/认知/情绪"三种爽里至少一种了吗？
□ 有意料之外的转折吗？
□ 结尾金句能当标题吗？
□ 留互动钩子了吗？
□ 不踩合规红线吗？
```
