## 固定风格词（每个 Prompt 都加，保证统一）

```
我的专属风格词：______________________________________
（示例：cinematic, ultra detailed, 8K, cyberpunk, blue holographic HUD, film grain）

我的主角锚定：________________________________________
（示例：25 yo Asian man, short black hair, grey hoodie —— 每镜都带，保证同一张脸）
```

## 制作流水线打勾（对照 04 章）

```
□ 出图（即梦/Flux/MJ），主角一致、风格统一
□ 图生视频（可灵/即梦/Runway），加轻运镜 + UI 动效
□ 配音（固定音色），关键句留停顿
□ 剪映合成：套 UI 包装模板（05）+ BGM + 节点音效
□ 自动字幕 → 统一样式 + 关键词高亮
□ 做封面（统一模板 + 系列编号）
```
