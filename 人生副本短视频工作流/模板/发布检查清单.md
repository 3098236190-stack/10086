# 模板 · 发布检查清单

> 每条视频发布前，从上到下过一遍。详见 [`../06-发布运营与SEO.md`](../06-发布运营与SEO.md) 和 [`../05-固定包装与视听规范.md`](../05-固定包装与视听规范.md)。

---

## 一、内容质量（00、03）
```
□ 前 3 秒有钩子（载入条 + 悬念句），没有废开场
□ 命中"代入/认知/情绪"三种爽里至少一种
□ 节奏紧、无废镜头，越往后越快
□ 结尾金句能立住，能当标题
□ 结局前留了 0.5s 停顿/悬念
```

## 二、固定包装（05）
```
□ 开场载入条 + 副本标题
□ 属性面板 / 等级条 / 结算面板齐全
□ 用的是固定那套配色 + 风格词
□ 字幕：固定字体/位置 + 关键词高亮
□ 开场音效 + 固定配音音色
□ 封面：统一模板 + 系列编号（EP.xx）
```

## 三、SEO 与标签（06）
```
□ 标题含"人生副本" + 副本名
□ 话题标签 5–8 个（核心词+形式词+情绪词+人群词）
□ 封面大字含关键词
□ 口播开场说出了"人生副本"四个字
```

## 四、互动设置（06、08）
```
□ 结尾有互动钩子（投票/提问/求评分）
□ 准备好置顶引导评论的文案
□ 若做 Universe：本集是否衔接上集投票结果？是否抛出下集投票？
```

## 五、合规（02、07）
```
□ 无违法/灰产方法教学，黑暗副本只做警示
□ 无擦边、无极端负面诱导
□ 无违规外链/联系方式硬导流
□ 带货（如有）为正规渠道、不夸大
```

## 六、发布动作（06）
```
□ 黄金时段发布（午 11:30–13:00 / 晚 18:00–22:00）
□ 发布后置顶引导评论
□ 发布后 1 小时内回复所有评论
□ 记录初始数据（5s 完播 / 完播率）到复盘表
```
