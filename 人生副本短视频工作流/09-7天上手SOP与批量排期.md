# 09 · 7 天上手 SOP 与批量排期

> 看完前面 8 章，这一章让你**7 天内发出第一条**，再转入"一天产一周量"的批量模式。照着打勾做即可。

---

## 一、7 天上手计划（从 0 到第一条）

### Day 1 · 定位（只做这一件，别贪快）
```
□ 读完 00、01 两章
□ 用 01 的"定位四件套"填出：角色 / 副本类型 / 视觉记忆点 / 固定开场白
□ 选定一套视觉风格（05）+ 一个固定配音音色
产出：一页《账号定位书》
```

### Day 2 · 建库（攒够弹药）
```
□ 读 02，从五大类里挑 20 个选题存进选题卡
□ 用"四变量组合公式"再扩 10 个
□ 按打分法选出最想做的 Top 3
产出：30 条选题 + Top 3
```

### Day 3 · 写剧本（打磨形式）
```
□ 读 03，用"一键生成提示词"（04）让大模型出 Top 3 的剧本
□ 人工精修：死磕 Hook（5s）和结尾金句
□ 用五幕模板定稿第 1 条
产出：第 1 条完整剧本 + 分镜表 + 图片 Prompt
```

### Day 4 · 做包装模板（一次做，永久用）
```
□ 读 05，在剪映/PS 里做好固定 UI 模板（载入条/属性面板/结算面板）
□ 确定字幕样式、开场音效、BGM 三件套
产出：可复用的《包装模板》（这是一次性投入，最值）
```

### Day 5 · 产出第 1 条
```
□ 按 04 流水线：出图 → 图生视频 → 配音 → 套包装模板 → 剪映合成
□ 做封面（05 规范）
产出：第 1 条成片 + 封面
```

### Day 6 · 发布 + 复盘
```
□ 读 06，埋好 SEO 关键词 + 话题标签
□ 黄金时段发布，置顶引导评论，1 小时内回复所有评论
□ 记录初始数据（5s 完播、完播率）
产出：第 1 条发布 + 数据基线
```

### Day 7 · 迭代 + 备货
```
□ 用 06 的"数据排查顺序"诊断第 1 条
□ 据此修正，产出第 2、3 条
□ 规划下周批量
产出：第 2-3 条 + 下周计划
```

## 二、批量生产 SOP（稳定期 · 一天产一周量）

跑顺后，**别再一条一条做**，改成"同工序集中干"（详见 [`04`](04-AI制作流水线与Prompt.md) 第六节）：

```
集中写：大模型一次出 7 条剧本（同人设、不同副本）          约 60 分钟
集中画：7 条所有图片 Prompt 排批，一次性出图               约 90 分钟
集中配：同一音色，一次配完 7 条旁白                        约 30 分钟
集中剪：第 1 条做成剪映草稿模板，其余 6 条替换素材          约 120 分钟
排期发：7 条排进一周，错峰发布                            约 15 分钟
                                              合计 ≈ 半天产出一周内容
```

> 核心：**模板化 + 工序化**。第一条慢没关系，它是你后面所有视频的"母版"。

## 三、周度排期表（直接套）

| 周几 | 动作 |
|------|------|
| 周一 | 集中写本周 7 条剧本 + 扩选题库 30 分钟 |
| 周二 | 集中出图 + 图生视频 |
| 周三 | 集中配音 + 集中剪辑（套模板） |
| 周四 | 做封面 + 埋词 + 排好发布计划 |
| 周五–周日 | 系统按计划发布；每天花 30 分钟运营评论区 + 记数据 |
| （周日晚）| 周复盘：看哪条最好，下周加大同类型 |

---

## 四、关键指标看板（每周复盘填）

| 指标 | 健康线 | 不达标怎么办 |
|------|--------|------------|
| 5 秒完播率 | > 45% | 改钩子（03 钩子库） |
| 完播率 | > 20% | 压时长、提节奏 |
| 点赞率 | > 3% | 强化金句/情绪（03） |
| 评论率 | 越高越好 | 加投票/提问钩子（08） |
| 转发率 | 越高越好 | 加人群指向性 |
| 周涨粉 | 持续为正 | 强化系列感 + 人设（08） |

> 复盘只问一句：**这周哪条最好、为什么？下周把"为什么"复制到更多条。**

---

## 五、常见坑（避雷）

```
× 第一条就追求完美 → 拖到不发。先发，再迭代。
× 一上来日更堆量 → 牺牲质量。形式 > 数量（参考 9 条 3.7 万粉）。
× 每条人设/包装都换 → 没辨识度。固定下来别动（05）。
× 黑暗副本擦边 → 限流封号。守红线（02），只做警示。
× 信任没建立就猛带货 → 掉粉掉权重。先立人设再变现（07）。
× 单打独斗不复盘 → 凭感觉。用数据看板（本章四）。
```

## 全流程闭环回顾

```
00 为什么爆 → 01 定位 → 02 选题 → 03 剧本 → 04 制作 → 05 包装
→ 06 发布 → 07 矩阵变现 → 08 升级 Universe → 09 批量执行 → 回到 02 扩库
```

> 这是一个**可以无限转下去的飞轮**。现在，回到 Day 1，开始做你的第一条。
