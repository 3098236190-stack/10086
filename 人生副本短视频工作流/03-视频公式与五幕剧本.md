# 03 · 视频公式与五幕剧本（STEP 2+3）

> 几乎所有爆款都遵循同一条公式。**把公式背下来，选题填进去，就是一条视频。**

---

## 一、统一视频公式（九段式 · 背下来）

```
① Hook（钩子，0–3s）         → 载入提示 + 抛出最大悬念
② 身份介绍（3–8s）           → "本次随机到的身份是……"
③ 出生 / 开局（8–15s）       → 出身、家境、天赋（定基调）
④ 成长（15–25s）             → 求学/入行，铺垫第一次分叉
⑤ 第一次选择（25–35s）       → A/B 抉择，命运第一次分叉
⑥ 第二次选择 / 转折（35–45s） → 加码，赌注变大
⑦ 重大事件（45–55s）         → 随机事件引爆高潮（机遇/灾难）
⑧ 人生结局（55–65s）         → 给出 ENDING + 评分面板
⑨ 总结 / 互动（65–70s）      → 一句金句落点 + 互动钩子
```

**时长建议**：30–70 秒为主。新手先做 45–60 秒；想冲完播率就压到 35–45 秒。
**节奏铁律**：每段对应一两个画面，**画面跟着旁白走、不留废镜头**；越往后节奏越快，结局前 0.5 秒可留一个"停顿+黑屏"制造期待。

## 二、五幕剧本结构（STEP 3 的可填空模板）

把九段式归并成五幕，方便写作和分镜：

### 第一幕 · 副本开启（对应①②）
```
【副本载入中…… ▓▓▓▓░░ 67%】
人生副本：《______ 的一生》
本次随机身份：______
开局难度：★★★☆☆
```

### 第二幕 · 出生与成长（对应③④）
```
你出生在 ______（年代/地点/家境）。
父母 ______。你获得初始天赋：______。
你一路 ______（求学/打工/入行），终于站在了第一个岔路口。
```

### 第三幕 · 第一个选择（对应⑤）
```
【选择 1】
A. ______（稳妥但平庸）
B. ______（冒险但有上限）
你选了 ____。命运的齿轮开始转动。
```

### 第四幕 · 随机事件与第二次选择（对应⑥⑦）
```
【随机事件触发！】
______（失业 / 暴富 / 重病 / 遇贵人 / 被骗 / 风口）
【选择 2】A. ______  B. ______
你选了 ____。这一次，没有回头路。
```

### 第五幕 · 结局与评分（对应⑧⑨）
```
【人生结算】
财富 ★★☆☆☆   健康 ★★★★☆
家庭 ★★★☆☆   快乐 ★★★★★   成就 ★★☆☆☆
ENDING：______（普通结局 / 隐藏结局 / BAD END / 真结局）

旁白金句：______
互动钩子：如果是你，第一步会选 A 还是 B？评论区告诉我。
```

> 空白版见 👉 [`模板/五幕剧本模板.md`](模板/五幕剧本模板.md)，每条视频复制一份来填。

## 三、完整范例脚本（可直接念）

### 范例 1：《AI 创业者的一生》（未来/创业副本）

```
（①Hook）正在载入人生副本……本次身份：一个在 AI 时代孤注一掷的普通人。
（②身份）系统提示：你没有背景，没有资源，只有一台电脑和一个不甘心。
（③出生）你出生在 2000 年，小城市，父母是普通工人，初始天赋：学得快、脸皮薄。
（④成长）2022 年大学毕业，行业寒冬，投了 100 份简历，回音 3 个。
（⑤选择1）岔路口出现——A：考公，安稳一生；B：All in 刚出现的 AI。你点了 B。
（⑥转折）第一次创业，做了个没人用的产品，赔光积蓄，女朋友也走了。
（⑦重大事件）【随机事件】你没删项目，把它改成了一个 AI Agent，半夜发到网上——第二天，服务器挤爆了。
（⑧结局）28 岁，公司估值过亿。【结算】财富★★★★☆ 健康★★☆☆☆ 快乐★★★☆☆。ENDING：逆袭结局（达成率 3%）。
（⑨金句+互动）系统总结：你没有赢在选择多，你赢在选了 B 之后，再也没回头。
如果是你，会选 A 考公，还是 B 押注？评论区见。
```

### 范例 2：《外卖员的一生》（职业副本 · 小人物共鸣向）

```
（①Hook）人生副本载入中……本次随机身份：一名外卖骑手，开局难度，地狱级。
（②身份）系统提示：你的对手不是别的骑手，是红灯、暴雨，和系统派给你的时间。
（③出生）你 19 岁，初中毕业，从老家来到这座吞人的城市。
（④成长）你学会了在 3 分钟内爬完没有电梯的 6 楼，也学会了对差评说对不起。
（⑤选择1）A：忍着，多接单多赚钱；B：辞职，回老家。雨季里，你选了 A。
（⑦重大事件）【随机事件】一次闯红灯，你为了一单 4 块钱的超时，差点没能回家。那天你在医院想通了一件事。
（⑥选择2）A：继续跑；B：用攒下的钱学一门手艺。这次，你选了 B。
（⑧结局）三年后，你有了自己的小修车铺。【结算】财富★★★☆☆ 健康★★★★☆ 快乐★★★★☆。ENDING：上岸结局。
（⑨金句+互动）系统总结：这个副本没有捷径，但永远有第二个选择。
你身边有没有这样拼命的人？把这条转给他。
```

> 注意两条范例的差别：范例 1 走"爽/逆袭"，范例 2 走"共鸣/心疼"——对应 [`00`](00-为什么能爆.md) 说的三种爽。**每条至少占一种。**

## 四、钩子库（前 3 秒，直接套）

钩子决定 5 秒完播率，是命门。挑一个套：

```
· 正在载入人生副本……本次随机身份：______，开局难度，地狱级。
· 警告：你即将体验一段 99% 的人会后悔的人生。
· 如果人生可以重开，这一次，你抽到的是 ______。
· 系统检测到你想知道"当 ______ 是什么体验"，已为你生成模拟。
· 这是一个普通人能拿到的最差开局，但他打出了隐藏结局。
· 模拟开始：一个 ______，从出生到死亡，只需要 60 秒。
· 倒计时 60 秒，体验完一个 ______ 的一生，你还敢抱怨现在吗？
```

> 公式：**"载入/警告/如果" + 身份 + 一个反差或悬念**。

---

## 五、金句库（结尾落点，直接套）

结尾一句话决定点赞和转发。按情绪基调挑：

**认知/顿悟向**
```
· 这局没有最优解，只有"选了就别回头"。
· 你不是输在选择少，是输在每个选择都想要。
· 人生最大的隐藏机制，叫"信息差"。
· 难的从来不是选择，是承担选择的后果。
```

**共鸣/治愈向**
```
· 这个副本没有捷径，但永远有第二个选择。
· 你已经打得很好了，只是这关本来就难。
· 有人开局地狱级，却把它打成了通关示范。
```

**警示向（黑暗副本专用）**
```
· 系统警告：此路线 99% 通向 BAD END，建议立即退出。
· 来钱最快的路，往往写在刑法里。
· 你以为是机会，系统标注的是"陷阱"。
```

## 六、互动钩子库（拉评论率，结尾必加）

```
· 如果是你，第一步会选 A 还是 B？
· 这一局，你给自己打几分？（满分 100）
· 你想看下一个副本是什么？评论区点单。
· 你身边有这样的人吗？把这条转给 TA。
· 下一集的结局，由你们投票决定：A 继续 / B 收手。
```
