# 00 · 为什么能爆（赛道底层逻辑）

> 这是整套工作流最重要的一章。看懂"为什么爆"，你才能在套模板时知道**哪里不能省、哪里可以变**。
> 一句话：**顶级母题（模拟人生）× AI 让供给成本暴跌 × 抖音算法奖励高情绪高完播**——三股力叠加。

---

## 一、需求侧：「模拟人生」是人类的顶级母题

- 《人生重开模拟器》上线时曾创下 **3 天约 20 亿访问量**的纪录——一个纯文字小游戏，证明"换一种活法、看别人/自己的一生"是**最大公约数级别的需求**。
- 人为什么爱看？因为现实里人生**不可重来、不可预览、不可对比**。而"人生副本"用 60 秒满足了三件现实做不到的事：
  1. **重开**——"如果我当初选了 B 会怎样"
  2. **预览**——"当程序员/交易员/外卖员到底是什么体验"
  3. **上帝视角**——旁观一整段人生的起落，获得掌控感
- 所以这类内容的情绪是**确定会被触发**的：好奇、代入、唏嘘、共鸣、警醒。不是"可能有人喜欢"，而是"几乎所有人都会停下来看一眼"。

**结论**：选题选得对，爆款概率有保障——这也是你说的"选题占 80% 爆款概率"的根因。

---

## 二、算法侧：抖音的推荐机制天然偏爱这种内容

抖音的初始推荐 = 把视频丢进小流量池，看几个核心指标决定要不要加推。这套内容恰好**每个指标都占便宜**：

| 算法指标 | 权重 | 「人生副本」为什么占优 |
|---------|------|----------------------|
| **完播率 / 平均播放时长** | 最高 | 第一人称叙事 + "结局未揭晓"=强追看欲，60 秒一口气看完 |
| **5 秒完播率** | 高 | "正在载入人生副本：XXX"的开场=天然钩子，5 秒留人 |
| **复播率** | 高 | 信息密度高、UI 元素多，很多人会回看细节 |
| **互动率（评论）** | 高 | "你会选 A 还是 B""我这条命算几分"=天然引导评论 |
| **转发率** | 很高 | "这说的不就是我吗"→转给特定的人（打工人转给打工人） |
| **关注转化** | 高 | 系列化 + 固定人设 → "想看下一集"→关注 |

> 关键：算法本质在做**情绪识别 + 时长统计**。这套内容是**高情绪密度 + 高完播**的组合，等于把算法想要的全给了。

**对工作流的指令**：
- 钩子（5 秒）和结局（最后 5 秒）是命门，**永远多花时间打磨**。
- 结尾必须留**互动钩子**（投票 / 提问 / 求评分），把评论率拉起来。

---

## 三、供给侧：AI 让"工业化生产"成为可能（这才是 2026 的新变量）

为什么这个赛道是**现在**爆，而不是三年前？因为以前做一条"模拟一生"的视频要实拍/找演员/做特效，成本几千上万；现在：

- **剧本**：大模型 1 分钟生成一版五幕剧本（STEP 2+3）。
- **画面**：文生图（Flux / 即梦 / Midjourney）+ 图生视频（可灵 Kling / Runway / Veo）几块钱一镜。
- **配音**：TTS / 剪映朗读几秒钟搞定，音色统一。
- **包装**：UI 模板一次做好，永久复用（STEP 6）。

**单条成本从"几千元"降到"几元 + 半小时"**，于是一个人就能日产多条、做矩阵。这就是"AI 工业化版"的底气——
**门槛被 AI 拉平了，红利期就是拉平之后、大众反应过来之前的这段时间。**

---

## 四、内容侧：它精准命中了三种"爽"

观众愿意看完 + 点赞 + 转发，是因为同时拿到了三种心理回报：

1. **代入爽（沉浸）**：第一人称"你出生在……你获得了……"——观众是主角，不是旁观者。
2. **认知爽（顿悟）**：把人生道理翻译成游戏机制——"原来内耗是同时开了太多支线""信息差是隐藏机制"。被"重新解释了一遍世界"的快感。
3. **情绪爽（共鸣/宣泄）**：唏嘘、心疼、不服、警醒——尤其"黑暗副本"和"小人物副本"，让人替角色（也替自己）出一口气或捏一把汗。

**做内容时自检**：这条视频，三种爽里至少占一种吗？一种都不占，大概率不会爆。

---

## 五、它的"天花板"和"护城河"在哪

诚实地说，目前大多数账号的护城河**很浅**——形态高度同质（AI 配图 + 第一人称念稿），谁都能模仿（包括你）。这既是机会也是风险：

- **机会**：你现在进场，技术门槛已被 AI 抹平，**靠选题质量 + 包装辨识度 + 更新频率**就能挤进去。
- **风险**：如果你也只做"AI 配图 + 念稿"，三个月后会淹没在模仿号里。

**真正的护城河有三层**（越往后越难被抄）：

1. **辨识度**：固定 UI / 固定开场音 / 固定人设——让人划到就知道是你（STEP 6）。
2. **系列化世界观**：不是零散选题，而是"人生副本宇宙"，可追更、有期待（STEP 8）。
3. **互动机制**：观众投票决定下一集走向——把"看客"变成"玩家"，别人抄不走你的社区（STEP 8）。

> 所以本工作流的目标不是教你做"一条爆款"，而是教你做"一个能持续爆、且越做越难被替代的账号"。

---

## 六、一页纸总结（贴在工位上）

```
为什么能爆 = 顶级母题 × AI 降本 × 算法偏爱
            （模拟人生）  （工业化）  （高完播高情绪高转发）

做每条视频前问自己 4 句：
  1. 钩子能在 5 秒内让人想看下去吗？
  2. 它命中"代入/认知/情绪"三种爽里的哪一种？
  3. 结尾留互动钩子了吗？（投票/提问/求评分）
  4. 一眼能认出是我的号吗？（固定 UI / 开场 / 人设）

4 句都 yes → 发；有 no → 改。
```
