# 基智汇 · 基金资讯 + 投教门户

面向「理财小白」与「进阶基民」双受众的**基金资讯门户 + 投资者教育平台**演示项目。
核心理念：**小白友好、进阶够用**，并在全站内置合规风险提示。

> ⚠️ 本项目为产品原型演示，站内所有基金、净值、收益、排名等均为**虚构演示数据**，不代表任何真实产品，不构成任何投资建议。

## ✨ 功能模块

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 首页 | `index.html` | 大盘概览、快捷工具、投教精选、市场行情 TOP10、资讯要闻 |
| 基金筛选器 | `screener.html` | **新手向导模式**（3 步问答智能匹配）+ **进阶专业模式**（多维度筛选、排序、对比、分页） |
| 基金详情 | `fund-detail.html` | 业绩概览、净值走势图（含同类/沪深300对比）、资产配置、持仓、基金经理、进阶数据（折叠）、费率 |
| 投教课堂 | `education.html` | 小白入门篇 + 进阶提升篇知识库、学习路径、定投计算器、风险测评 |
| 策略专栏 | `strategy.html` | 小白友好策略 + 进阶实战策略，只讲方法逻辑、不荐基 |
| 市场资讯 | `news.html` | 行业要闻 / 公司公告 / 观点解读 |
| 我的自选 | `watchlist.html` | 基于 localStorage 的自选基金管理 |

## 🎯 双受众设计

- **理财小白**：首屏入门入口、生活化类比的投教内容、3 步选基向导、通俗业绩评级（优秀/良好/一般）、风险测评。
- **进阶基民**：多维度筛选器（风险指标 / 夏普 / 回撤 / 经理任职等）、基金对比、净值对比图、业绩归因与持有人结构等深度数据。

## 🛡️ 合规设计

- 顶部合规条 + 页脚风险声明常驻：「市场有风险，投资需谨慎 · 历史业绩不代表未来表现」。
- 所有收益数据、费率、排名旁标注风险/参考提示。
- 内容只讲方法逻辑，**不推荐具体基金、不预测走势、不承诺收益**，每篇投教文章结尾标注「不构成投资建议」。
- 全站杜绝「必赚 / 稳赢 / 无风险 / 保本」等违规表述。

## 🧱 技术栈

零依赖的纯静态站点：原生 **HTML + CSS + JavaScript**，无需构建步骤。

- `css/style.css` —— 设计系统（深蓝 + 浅绿 + 橙色主色，红涨绿跌，响应式）
- `js/data.js` —— 演示数据层（基金 / 投教 / 策略 / 资讯，净值曲线按种子生成）
- `js/site.js` —— 全站通用：导航、页脚、搜索、自选存储、Toast
- `js/charts.js` —— 轻量 SVG 图表（折线含悬停、环形、柱状）
- 其余 `js/*.js` —— 各页面逻辑

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可；或启动一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

也可直接部署到 GitHub Pages（根目录托管）。

## 🧪 端到端测试（Playwright）

`tests/e2e/` 下为 Playwright 端到端用例，覆盖**桌面端 + 移动端**两套设备，
按真实用户流程走查（向导选基、筛选/排序/对比/导出、详情图表、定投计算器、
风险测评、自选分组备注、搜索等），并包含边界 / 异常场景（对比上限拦截、
非法基金代码、搜索无结果、计算器极值等），秉持「找茬」思想同时校验 UI 与 UX。

```bash
npm install
npx playwright install chromium   # 若网络可访问 Playwright CDN
npm run test:e2e                  # 桌面 + 移动全部
npm run test:e2e:mobile           # 仅移动端
```

> 若环境无法下载 Playwright 自带浏览器，可设置 `CHROME_BIN` 指向本机已有的
> Chromium/Chrome 可执行文件后再运行。
