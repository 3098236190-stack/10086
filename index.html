HOW IT WORKS · 原理速览

从一句提示词，到一段声音

像 Suno、Udio 这类 AI 音乐系统，本质是一条「文本条件 → 神经网络生成音频 → 解码成波形」的流水线：用大语言模型理解提示词与歌词，用神经音频编解码器把声音压成离散 token，再由 Transformer（自回归）配合扩散模型预测并细化这些 token，最终还原成带人声的完整音频。 本页是浏览器内的实时程序化合成 demo，借用了同一套「提示词驱动生成」的思路——下面是四个阶段，以及本页的对应实现。

01 · 文本编码

提示词 → 向量

用 T5 等文本编码器，把自然语言描述与歌词编成「音乐描述向量」，作为生成的条件信号。

本页：analyzePrompt 解析情绪词（清亮/柔和/坚定/空灵…），换算成节奏、能量、明亮度与调式偏置。

02 · 音频离散化

波形 → token

EnCodec、Descript Audio Codec 等神经编解码器把连续波形压成可逆的离散 token，让模型能像处理文字一样处理声音。

本页：跳过 codec，直接用 Web Audio 振荡器即时合成音色。

03 · 生成模型

Transformer + 扩散

自回归 Transformer 在文本条件下逐个预测音频 token，扩散模型再做高保真细化，保证连贯与音质。

本页：确定性的 16 步序列器 + 调式/和弦规则，同一(提示词+种子)=同一段音乐。

04 · 解码成声

token → 波形

编解码器的解码端把 token 还原成完整波形（人声+伴奏），并支持多候选与「续写/扩展」。

本页：前瞻调度器实时播放，「自动续写」每 32 步重组一次乐段。

原理参考： How Suno AI Creates Music (musicgeneratorai.io)、 How Suno & Udio work — technical view (VI-CONTROL)、 Long-form music generation with latent diffusion (arXiv:2404.10301)。 本页为独立的程序化合成演示，与上述产品无从属关系。
