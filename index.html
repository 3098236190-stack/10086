人生副本 · 短视频工作流（AI 工业化版）

一套可复制、可批量、可长期运营的「人生副本」赛道短视频生产 SOP。 核心回答两个问题：它为什么能爆 + 怎么搭一套可复制的工作流。

一句话讲清这个赛道

把一段人生当成一个游戏副本来通关解说—— 出身是「开局」，职业是「职业副本」，高考/求职/婚姻是「关卡」，裁员/疾病/机遇是「随机事件」， 最后给出「人生评分」。用第一人称沉浸式叙事 + 游戏化 UI 包装，让观众在 60 秒里体验另一种人生。

它能爆的根本：模拟人生是顶级母题（《人生重开模拟器》曾 3 天 20 亿访问量）， 而 AI 把"做一条这样的视频"的成本从几千元降到几块钱——需求一直在，供给端刚被 AI 打开。 完整分析见 👉 00-为什么能爆.md（这是本工作流的灵魂章节）。

赛道时间窗：2026 年 6 月，抖音搜【人生副本】已出现大量模仿号，红利期开始但远未饱和，且大多数模仿号停留在"AI 配图 + 第一人称念稿"的初级形态——升级空间巨大（见 08）。

核心心法（先记住这 6 条）

  1. 形式 > 数量：好形式能让 9 条视频做到几万粉（参考"人生体验服"），别一上来追日更。
  2. 前 3 秒定生死：钩子勾不住人，后面全白搭。每条先磨"载入提示"和第一句。
  3. 认知爽感 + 情绪共鸣，二选一必须有：观众点赞要么"被说中"，要么"原来如此"。
  4. 包装一致 = 品牌：固定 UI（Loading / Lv / HP / 评分面板）+ 固定开场，让人一眼认出你。
  5. 别做纯模仿：选一个细分人群/独特副本类型切入，差异化在 01。
  6. 合规第一：黑暗类副本（赌徒、诈骗园区等）一律以警示/反诈/剧情体验角度做，不教方法、不美化（见 02 合规红线）。

本工作流为内容生产 SOP。工具与平台为 2026 年 6 月中国大陆主流方案，可按实际替换。 数据来源：用户提供的对标账号数据 + 公开赛道观察。

00 · 为什么能爆（赛道底层逻辑）

这是整套工作流最重要的一章。看懂"为什么爆"，你才能在套模板时知道哪里不能省、哪里可以变。 一句话：顶级母题（模拟人生）× AI 让供给成本暴跌 × 抖音算法奖励高情绪高完播——三股力叠加。

一、需求侧：「模拟人生」是人类的顶级母题

  • 《人生重开模拟器》上线时曾创下 3 天约 20 亿访问量的纪录——一个纯文字小游戏，证明"换一种活法、看别人/自己的一生"是最大公约数级别的需求。
  • 人为什么爱看？因为现实里人生不可重来、不可预览、不可对比。而"人生副本"用 60 秒满足了三件现实做不到的事： 1. 重开——"如果我当初选了 B 会怎样" 2. 预览——"当程序员/交易员/外卖员到底是什么体验" 3. 上帝视角——旁观一整段人生的起落，获得掌控感
  • 所以这类内容的情绪是确定会被触发的：好奇、代入、唏嘘、共鸣、警醒。不是"可能有人喜欢"，而是"几乎所有人都会停下来看一眼"。

结论：选题选得对，爆款概率有保障——这也是你说的"选题占 80% 爆款概率"的根因。

二、算法侧：抖音的推荐机制天然偏爱这种内容

抖音的初始推荐 = 把视频丢进小流量池，看几个核心指标决定要不要加推。这套内容恰好每个指标都占便宜：

算法指标 权重 「人生副本」为什么占优
完播率 / 平均播放时长 最高 第一人称叙事 + "结局未揭晓"=强追看欲，60 秒一口气看完
5 秒完播率 高 "正在载入人生副本：XXX"的开场=天然钩子，5 秒留人
复播率 高 信息密度高、UI 元素多，很多人会回看细节
互动率（评论） 高 "你会选 A 还是 B""我这条命算几分"=天然引导评论
转发率 很高 "这说的不就是我吗"→转给特定的人（打工人转给打工人）
关注转化 高 系列化 + 固定人设 → "想看下一集"→关注

关键：算法本质在做情绪识别 + 时长统计。这套内容是高情绪密度 + 高完播的组合，等于把算法想要的全给了。

对工作流的指令： - 钩子（5 秒）和结局（最后 5 秒）是命门，永远多花时间打磨。 - 结尾必须留互动钩子（投票 / 提问 / 求评分），把评论率拉起来。

三、供给侧：AI 让"工业化生产"成为可能（这才是 2026 的新变量）

为什么这个赛道是现在爆，而不是三年前？因为以前做一条"模拟一生"的视频要实拍/找演员/做特效，成本几千上万；现在：

  • 剧本：大模型 1 分钟生成一版五幕剧本（STEP 2+3）。
  • 画面：文生图（Flux / 即梦 / Midjourney）+ 图生视频（可灵 Kling / Runway / Veo）几块钱一镜。
  • 配音：TTS / 剪映朗读几秒钟搞定，音色统一。
  • 包装：UI 模板一次做好，永久复用（STEP 6）。

单条成本从"几千元"降到"几元 + 半小时"，于是一个人就能日产多条、做矩阵。这就是"AI 工业化版"的底气—— 门槛被 AI 拉平了，红利期就是拉平之后、大众反应过来之前的这段时间。

四、内容侧：它精准命中了三种"爽"

观众愿意看完 + 点赞 + 转发，是因为同时拿到了三种心理回报：

  1. 代入爽（沉浸）：第一人称"你出生在……你获得了……"——观众是主角，不是旁观者。
  2. 认知爽（顿悟）：把人生道理翻译成游戏机制——"原来内耗是同时开了太多支线""信息差是隐藏机制"。被"重新解释了一遍世界"的快感。
  3. 情绪爽（共鸣/宣泄）：唏嘘、心疼、不服、警醒——尤其"黑暗副本"和"小人物副本"，让人替角色（也替自己）出一口气或捏一把汗。

做内容时自检：这条视频，三种爽里至少占一种吗？一种都不占，大概率不会爆。

五、它的"天花板"和"护城河"在哪

诚实地说，目前大多数账号的护城河很浅——形态高度同质（AI 配图 + 第一人称念稿），谁都能模仿（包括你）。这既是机会也是风险：

  • 机会：你现在进场，技术门槛已被 AI 抹平，靠选题质量 + 包装辨识度 + 更新频率就能挤进去。
  • 风险：如果你也只做"AI 配图 + 念稿"，三个月后会淹没在模仿号里。

真正的护城河有三层（越往后越难被抄）：

  1. 辨识度：固定 UI / 固定开场音 / 固定人设——让人划到就知道是你（STEP 6）。
  2. 系列化世界观：不是零散选题，而是"人生副本宇宙"，可追更、有期待（STEP 8）。
  3. 互动机制：观众投票决定下一集走向——把"看客"变成"玩家"，别人抄不走你的社区（STEP 8）。

所以本工作流的目标不是教你做"一条爆款"，而是教你做"一个能持续爆、且越做越难被替代的账号"。

六、一页纸总结（贴在工位上）

为什么能爆 = 顶级母题 × AI 降本 × 算法偏爱
            （模拟人生）  （工业化）  （高完播高情绪高转发）

做每条视频前问自己 4 句：
  1. 钩子能在 5 秒内让人想看下去吗？
  2. 它命中"代入/认知/情绪"三种爽里的哪一种？
  3. 结尾留互动钩子了吗？（投票/提问/求评分）
  4. 一眼能认出是我的号吗？（固定 UI / 开场 / 人设）

4 句都 yes → 发；有 no → 改。

01 · 赛道分析与账号定位

目标：拆透 5 个对标号的"可复制点"，然后帮你定一个不会淹死在模仿号里的差异化人设。

一、5 个对标账号深度拆解

三个关键洞察

  1. 形式 > 数量：人生体验服 9 条 3.7 万粉、剧本人生 33 条 16 万粉。说明起号靠"形式 + 选题"，不靠日更堆量。先把一个好形式打磨出来，再考虑产量。
  2. 人设是辨识度的核心：夫子、模拟员、观察员、体验服——每个号都把自己角色化了。你也必须有一个"它是谁"的角色。
  3. 同质化已经开始：5 个号的底层都是"AI 画面 + 旁白叙事 + 游戏化包装"。谁先建立更强的辨识度和系列感，谁就能从模仿潮里浮上来。

二、把"人设"拆成 4 个可设计的变量

别凭感觉起人设，按这 4 个变量组合，就能造出一个独特角色：

变量 选项举例 决定了什么
叙事视角 第一人称"你"／第二人称代入／第三方旁观／系统播报 沉浸感 vs 客观感
角色身份 系统 AI／夫子智者／冷峻观察员／游戏 GM／时间管理局／轮回管理员 口吻、立场、金句风格
情绪基调 治愈温暖／犀利毒舌／冷静克制／热血燃／悬疑暗黑 吸引哪类人群
声音/语速 沉稳男声／知性女声／机械电子音／少年音 听感记忆点

举例组合（直接可用）： - 「轮回管理局」：系统 AI 视角 + 机械电子音 + 冷静克制 → 适合做职业副本、历史副本。 - 「人生劝退师」：第二人称 + 犀利毒舌 + 知性女声 → 适合做黑暗副本、避坑警示。 - 「副本通关师」：夫子视角 + 热血燃 + 沉稳男声 → 适合做逆袭、攻略类。

三、差异化定位：怎么不做"纯模仿号"

模仿号会死在同质化里。用下面任意一条做出区隔，就能活下来；用两条以上，就能跑出来。

路线 A：切细分人群（最稳）

不做"所有人的人生"，只做某一类人的副本，做深做透： - 打工人副本宇宙 / 宝妈副本 / 小镇青年副本 / 35+ 中年副本 / 考研考公副本 / 县城体制内副本 - 好处：人群精准 → 转发率高（"这说的就是我"）→ 涨粉快 → 后期变现路径清晰。

路线 B：切独特副本类型

别人都做职业副本，你做别人没系统做的： - 历史副本（科举考生/锦衣卫/御医）、未来副本（火星移民/数字永生）、关系副本（婚姻/原生家庭）。

路线 C：切独特包装/视觉

同样的内容，换一套没人用过的视觉语言就能区隔： - 水墨国风 UI、像素游戏风、极简黑金终端风、监控/档案风（见 05）。

路线 D：切互动机制（最强护城河）

做"观众投票决定下一集"的可追更剧情——这是别人最难抄的（见 08）。

建议组合：路线 A（细分人群）+ 路线 C（独特视觉）打底，跑顺后上路线 D（互动）。

四、起号前的定位四件套（填完再开工）

把下面四行填满，就是你的账号定位书：

1. 我的角色是谁：____________（如：轮回管理局的 AI 管理员）
2. 我专做哪类副本：__________（如：打工人 / 职业副本，主攻 22-35 岁职场人）
3. 我的视觉记忆点：__________（如：黑金终端风 UI + 蓝色全息血条）
4. 我的固定开场白：__________（如："欢迎登录人生副本，本次随机到的身份是……"）

这四件套一旦定下，不要轻易改——辨识度来自重复。

①身份 ②时代/地点 ③核心变量 ④视角

示例：程序员 × 2050 AI 时代 × 被自己写的 AI 取代 × 第一人称 → 《我是 2050 年最后一个程序员》。 示例：科举考生 × 大明 × 考到 50 岁才中 × 旁观者 → 《他考了 30 年，中举那天却……》。

4 个变量各列 10–30 个选项，相乘就是成百上千个选题。每周花 30 分钟扩库，永远不缺题。

选题灵感的 5 个挖掘渠道

  1. 评论区：自己和对标号视频下，观众喊"求做 XX"的，直接做。
  2. 热搜/热点：把当下热点人物/事件包装成副本（如某职业上热搜 → 做该职业副本）。
  3. 百度/知乎搜"XX 是一种怎样的体验"：高赞回答就是现成剧本素材。
  4. 对标号反推：把对标号的爆款选题，换一个人群/时代/视角重做（合规改编，非搬运）。
  5. 自己的人生：你或身边人真实经历过的副本，细节最真、最容易爆。

三、选题打分筛选法（决定先做哪条）

每个选题按下面 5 项各打 1–2 分，总分 ≥ 7 分的优先做：

维度 问自己 满分
代入感 观众容易把自己代入吗？ 2
情绪强度 能激起强情绪（唏嘘/不服/警醒/爽）吗？ 2
转发动机 观众会想转给某个特定的人吗？ 2
反差/转折 有没有意料之外的转折或结局？ 2
合规安全 不踩红线、不擦边、不教坏吗？ 2（一票否决）

合规这项是一票否决：打 0 分直接弃用，不管其他多高。

四、⚠️ 黑暗副本合规红线（必读，保号保命）

黑暗类传播最高，但也最容易被限流、封号甚至违法。死守以下红线：

绝对不做： - ❌ 教任何违法/灰产的具体方法、话术、流程（赌、骗、贷、传销等）。 - ❌ 美化、炫耀违法所得，或暗示"来钱快值得"。 - ❌ 为任何违法平台/项目引流、导流、留联系方式。 - ❌ 渲染血腥、暴力、自残、极端负面诱导。

正确姿势： - ✅ 以受害者视角 + 警示结局呈现："我以为能赚快钱，结果家破人亡"。 - ✅ 落点放在反诈、避坑、上岸："系统警告：此副本 99% 通向 BAD END，建议立即退出。" - ✅ 结尾给求助/正规出路信息（如反诈提示），传递正向价值。

一句话：黑暗副本做的是"劝退片"，不是"教学片"。平台规则和法律都站在劝退这边。

03 · 视频公式与五幕剧本（STEP 2+3）

几乎所有爆款都遵循同一条公式。把公式背下来，选题填进去，就是一条视频。

一、统一视频公式（九段式 · 背下来）

① Hook（钩子，0–3s）         → 载入提示 + 抛出最大悬念
② 身份介绍（3–8s）           → "本次随机到的身份是……"
③ 出生 / 开局（8–15s）       → 出身、家境、天赋（定基调）
④ 成长（15–25s）             → 求学/入行，铺垫第一次分叉
⑤ 第一次选择（25–35s）       → A/B 抉择，命运第一次分叉
⑥ 第二次选择 / 转折（35–45s） → 加码，赌注变大
⑦ 重大事件（45–55s）         → 随机事件引爆高潮（机遇/灾难）
⑧ 人生结局（55–65s）         → 给出 ENDING + 评分面板
⑨ 总结 / 互动（65–70s）      → 一句金句落点 + 互动钩子

时长建议：30–70 秒为主。新手先做 45–60 秒；想冲完播率就压到 35–45 秒。 节奏铁律：每段对应一两个画面，画面跟着旁白走、不留废镜头；越往后节奏越快，结局前 0.5 秒可留一个"停顿+黑屏"制造期待。

· 系统检测到你想知道"当 ______ 是什么体验"，已为你生成模拟。

五、金句库（结尾落点，直接套）

结尾一句话决定点赞和转发。按情绪基调挑：

认知/顿悟向

· 这局没有最优解，只有"选了就别回头"。
· 你不是输在选择少，是输在每个选择都想要。
· 人生最大的隐藏机制，叫"信息差"。
· 难的从来不是选择，是承担选择的后果。

共鸣/治愈向

· 这个副本没有捷径，但永远有第二个选择。
· 你已经打得很好了，只是这关本来就难。
· 有人开局地狱级，却把它打成了通关示范。

警示向（黑暗副本专用）

· 系统警告：此路线 99% 通向 BAD END，建议立即退出。
· 来钱最快的路，往往写在刑法里。
· 你以为是机会，系统标注的是"陷阱"。

· 如果是你，第一步会选 A 还是 B？

二、核心提示词：一键生成"剧本 + 分镜 + 图片 Prompt"

这是工业化的关键——让大模型一次产出能直接用的全套素材。复制下面整段，把【】里替换掉：

你是「人生副本」短视频的资深编导。请按以下要求，为我生成一条 60 秒短视频的完整制作包。

请严格按"九段式公式"输出，分三部分：

# 二、分镜表（每段对应 1 个镜头，列出：镜号 | 画面内容 | 景别 | 时长(秒) | 字幕关键词）

# 三、每个镜头的文生图 Prompt（英文，统一风格，便于直接粘贴到即梦/Flux/MJ）
风格统一为：【cinematic, first-person POV, 电影感打光, 高细节, 8K】
主角形象保持一致：______（如：25 岁亚洲男性，短发，灰色卫衣）

要求：情绪强、有反差、结尾留互动钩子；规避任何违法/敏感内容；金句要能当标题。

产出后人工再润色（尤其 Hook 和金句），不要直接全盘用。

三、分镜 Prompt 流水线（STEP 5）

图片 Prompt 通用公式

[主体/角色] + [场景/环境] + [动作/情绪] + [光线/氛围] + [镜头/视角] + [画质风格词]

固定画质风格词（每个 Prompt 都带，保证统一感）

cinematic, ultra detailed, 8K, dramatic lighting, film grain,
first-person POV（需要代入时）, depth of field

选一套专属风格词长期固定（如全部加 cyberpunk, blue holographic HUD），这就是你的视觉签名。

分镜 Prompt 范例（扩展你给的三镜，并补全一整条）

explosive turning point, screens lighting up with notifications, server room glowing,
intense dramatic lighting, sense of breakthrough, cinematic, ultra detailed, 8K

四、一致性技巧（让"同一个主角"贯穿全片）

AI 最大的坑是每张图人脸/风格都不一样。三招解决：

  1. 角色锚定：在每个镜头 Prompt 里写死主角特征（"25 yo Asian man, short black hair, grey hoodie"），或用工具的"角色参考/垫图"功能固定同一张脸。
  2. 风格锁定：所有图共用同一组风格词 + 同一色调（见 STEP 6）。可在即梦/MJ 用同一个风格参考图。
  3. 少切画面：能用"图生视频"让一张图动起来，就别频繁换图——少切换 = 强沉浸（这也是算法偏爱的，见 00）。

五、图生视频与配音要点

  • 图生视频：给静态图加"轻微运镜"（推/拉/摇）和元素动效（HUD 闪烁、进度条走动、人物微动），单镜 2–4 秒即可。不追求大动作，稳、有氛围比炫技重要。
  • 配音：选一个固定音色（如沉稳男声/电子机械音）长期用，它是你的听觉签名。语速适中、关键句留停顿。剪映"朗读"可一键生成，免费够用。
  • 字幕：剪映自动识别字幕 → 统一字体/描边/位置，关键词高亮变色（见 STEP 6）。

六、批量化技巧（一次做一周）

把流程拆成"同类工序集中干"，效率翻几倍：

  1. 集中写：一次让大模型出 7 条剧本（同一人设、不同副本）。
  2. 集中画：把 7 条的所有图片 Prompt 排成一批，一次性出图。
  3. 集中配：同一音色，一次配完 7 条旁白。
  4. 集中剪：第一条剪好存成剪映草稿模板，后面 6 条替换素材即可，UI 包装一次复用。
  5. 错峰发：7 条排进一周的发布计划（见 09）。

关键心法：把"做一条"变成"做一套"。模板做一次，复用一辈子。

06 · 发布运营与 SEO

视频做得好只是一半，发得对是另一半。这一章解决：怎么被搜到、被推到、被互动起来。

一、抖音 SEO：让"搜人生副本"的人搜到你

赛道有大量搜索流量（用户主动搜【人生副本】），把关键词埋进 4 个位置：

1. 标题/文案：必含"人生副本" + 副本名（如"人生副本：外卖员的一生"）
2. 话题标签：#人生副本 #人生模拟器 + 垂直词
3. 封面文字：大字直接写"人生副本 · ____的一生"
4. 视频口播/字幕：开场就说出"人生副本"四个字（语音也会被识别为搜索词）

搜索流量是"长尾复利"——一条视频能被搜半年。每条都埋词，不要嫌烦。

话题标签矩阵（每条选 5–8 个）

核心词：#人生副本 #人生模拟器 #人生重开
形式词：#AI视频 #第一人称 #沉浸式体验
情绪词：#人生感悟 #扎心 #治愈 #逆袭
人群词：#打工人 #职场 #小镇青年（按你的人群定位选）
蹭热词：当下相关热点话题（谨慎、相关才用）

二、发布时间与频率

项目 建议
黄金时段 中午 11:30–13:00、晚上 18:00–22:00（晚高峰最佳）
频率 起号期日更或隔日更（喂数据）；稳定后保证"系列可追更"的节奏

但记住 01 的洞察：形式 > 数量。宁可少而精，不要为日更牺牲质量。

三、冷启动：前 5 条 + 前 500 粉怎么破

新号没权重，靠这几招过初始流量池：

  1. 前 5 条是"定位锚"：必须同一人设、同一包装、同一类副本——让系统给你打准标签，也让进来的人知道"关注你能持续看到什么"。
  2. 死磕 5 秒完播：前 5 条把钩子打磨到极致，5 秒完播率 > 50% 才有加推。
  3. 发布后 1 小时是黄金期：发完盯着评论区，第一时间回复每条评论（拉互动权重）。
  4. 自己埋第一条神评论：发布后用小号/自己置顶一条引导性评论（见下）。
  5. 不要买量、不要互赞群：会污染账号标签，得不偿失。

四、评论区运营（被严重低估的涨粉/完播杠杆）

评论区是第二个内容场，运营好能二次拉升推荐：

  • 置顶引导评论：每条发完，自己置顶一条钩子评论，例： · "选 A 的扣 1，选 B 的扣 2，看看大家都怎么选👇" · "想看下一个副本是什么？点赞最高的我下条就做。" · "这局我给打 60 分，你们呢？"
  • 回复即追问：别人评论后，用反问把话题续下去（提升评论层数和停留）。
  • 从评论里挖选题：观众喊"求做 XX"——直接做，并 @ 他，形成"你点单我来做"的社区感。
  • 挑动良性站队：A/B 选择、不同结局，天然引发讨论，别怕有分歧（有争论=有互动）。

评论区里"点单—产出—@回应"的循环，是把看客变粉丝的关键，也是通往 08 互动机制的起点。

五、完播率优化清单（算法的命门指标）

□ 前 3 秒有钩子（载入条 + 悬念句）
□ 没有"大家好我是……"这种废开场
□ 节奏紧、无废镜头，越往后越快
□ 结局前留悬念/停顿，吊住最后 5 秒
□ 时长别贪长（先做 45–60s，完播不行就压短）
□ 字幕清晰、关键词高亮（静音也能看懂）

六、数据不好时的排查顺序

按这个顺序找问题，从前往后查（越靠前影响越大）：

完播率低（<15%）   → 钩子/节奏问题 → 改前 3 秒、压时长
完播高但点赞低     → 缺情绪/认知爽点 → 改结尾金句和高潮
点赞高但转发低     → 缺"转给某人"的动机 → 加人群指向性
互动低（评论少）   → 没留互动钩子 → 结尾加投票/提问
涨粉低（数据都还行）→ 缺系列感/人设 → 强化固定包装 + 可追更（08）

07 · 账号矩阵与变现（STEP 7）

一个号能起，一套号能赚。这一章解决：怎么用一套世界观扩成矩阵 + 怎么把流量变成钱。

一、账号矩阵：一套世界观，无限扩展

不要只做一个"人生副本"号。把它当成一个世界观母品牌，裂变出垂直子账号：

                    【人生副本】（母号/总 IP）
                          │
   ┌──────────┬──────────┼──────────┬──────────┐
 职业副本   历史副本   黑暗副本   AI副本    财富副本
   │          │          │          │          │
 创业副本   爱情副本   家庭副本   校园副本   ……（按需扩）

矩阵的 4 个好处

  1. 测赛道：哪个子号数据好，就重点投入哪个，等于多次下注。
  2. 抗风险：一个号被限流，其他号还在跑。
  3. 流量内循环：子号互相 @、引流、合拍，放大整体曝光。
  4. 批量复用：同一套 UI 包装、同一条流水线（04/05），开新号边际成本极低。

矩阵落地节奏

  • 第 1 个月：只做 1 个号，跑通流水线、验证人设。别一上来铺矩阵。
  • 数据验证后：复制流水线，每 2–4 周开 1 个垂直子号，各绑定一个细分人群（见 01）。
  • 统一品牌：所有子号共用 UI 风格 + 命名规则（如都叫"XX副本 by 人生副本"），强化母 IP。

⚠️ 多账号运营注意平台规则：避免同一设备/IP 批量操作触发风控，内容不要完全复制粘贴（同质化会被降权）。

路径 起量门槛 收益 说明

2. 星图广告/品牌植入 几万粉 中高 把品牌"植入"成副本里的道具/事件

4. 私域引流 任意 高（长期） 导流到公众号/微信，做复购和深度变现

② 星图广告：这套内容植入广告极自然——把品牌做成副本里的"装备/贵人/转折道具"。例："这一关，他用了【某 App】，命运开始反转。" 不破坏沉浸感，转化反而高。

③ 知识付费（最匹配）：你的人设是"看透人生规则的人"，天然适合卖： - 人生/职业规划课、认知思维课、AI 副业/AI 做视频课（教别人做这个赛道本身就是卖点）。 - 付费社群（"副本攻略局"），持续输出 + 答疑。

④ 私域引流（最该做）：抖音流量是租来的，私域才是自己的。 - 主页/评论区/视频结尾，合规引导加微信/公众号（注意平台对外链的规则，用"昵称/拼音"等软引导）。 - 私域里做课程、咨询、社群复购，客单价和复购远高于公域。

⑤ 带货：认知成长类书单和这套内容最搭（看完"人生副本"的人，想"提升自己"）。挂相关书、课、好物。

⑥ IP/账号变现：矩阵跑出来后，单个成熟号可转让，或接"代运营/陪跑"，或做 IP 授权周边。

08 · 人生副本 Universe（可追更内容宇宙）（STEP 8）

大多数账号停在"AI 配图 + 第一人称念稿"，谁都能抄。 这一章是把账号从"热门模板"升级成"可持续更新、越做越难被替代的内容宇宙"的关键——也是你真正的护城河。

为什么要做 Universe？

回顾 00 第五节：当前赛道护城河很浅，三个月后纯模仿号会互相淹没。 护城河有三层，越往后越难抄：辨识度（05）→ 系列化世界观 → 互动机制。 本章做的就是后两层：把零散选题变成一个有规则、有成长、有观众参与的世界。

核心思路一句话：不做"一条爆款"，做"一个停不下来的连续剧 + 养成游戏"。

五大系统（逐个落地）

系统 ①：技能树系统（让账号有"成长线"）

做法：主角每通关一个副本/做对一个选择，就解锁一项技能，并在 UI 上永久点亮。

技能树示例：沟通力 / 赚钱力 / 英语 / AI / 情绪管理 / 人脉 / 健康
表现：每集结尾弹出 "🔓 解锁新技能：AI（Lv.1→Lv.2）"

价值： - 观众产生"陪养成"的黏性——想看主角技能点满。 - 技能本身就是选题发生器（"解锁英语"那集 = 一个新副本）。 - 天然适配知识付费（07）："想点亮‘赚钱力’？攻略在主页。"

系统 ②：随机事件系统（让剧情有"不确定性爽感"）

做法：每集插入一个概率事件，用"骰子/转盘/系统抽取"的形式呈现。

事件池：贵人相助 / 突然裁员 / 创业风口 / 重病 / 中奖 / 被骗 / 遇见对的人
表现："🎲 随机事件触发：裁员（概率 23%）"，再接主角应对

价值： - "不知道会抽到什么"= 强追看欲，直接拉完播（00 算法逻辑）。 - 同一个身份，因随机事件不同 → 同一选题可重做多版，内容量翻倍。 - 真实感：人生本就充满随机，观众共鸣"这就是命"。

系统 ③：多结局系统（让一个副本能拍好几集）

做法：每个副本设计 普通结局 / 隐藏结局 / BAD END / 真结局 多个分支。

表现：结尾标注 "ENDING：普通结局（达成率 61%）｜还有 2 个隐藏结局未解锁"
玩法：先发普通结局 → 下集发隐藏结局 → 高潮放真结局

价值： - "还有隐藏结局没看到"= 强力追更钩子，提升完播 + 关注。 - 一个选题拆成 3–4 集 → 极大降低选题消耗，对工业化生产是关键。 - "达成率 3%"这种稀有度标注，激发"我也想要隐藏结局"的转发欲。

系统 ④：观众互动系统（最强护城河，别人抄不走）

做法：每集结尾抛出 A/B 选择，下一集按评论/点赞投票结果推进剧情。

结尾："这一步，A 辞职创业 / B 留下熬资历——评论区投票，点赞最高的，下集就走那条路。"
下集开头："上集你们选了 B，于是……"

价值： - 把"看客"变成"玩家/编剧"——这是 UI 和文案抄不走的东西，因为护城河是你的社区。 - 评论率、互动率爆炸（算法最爱），还制造"必须看下一集"的强追更。 - 形成"我们共同养出来的人生"的归属感 → 铁粉。

这是从 06 评论区运营自然长出来的机制，建议账号稳定后第一优先上线。

系统 ⑤：统一 UI 品牌（贯穿全宇宙的视觉宪法）

做法：固定 HUD、等级、属性面板、评分界面、技能树界面——所有子账号、所有副本通用。 （具体元素库见 05-固定包装与视听规范.md。）

固定不变：LIFE INSTANCE 载入界面 / Lv 等级条 / HP·Money·Age·Skill 面板 /
          技能树界面 / ENDING 五维评分面板 / 开场音效 + 配音音色

价值：一眼认出 + 跨账号统一 = 母 IP 资产。这是矩阵（07）能"像一个品牌"的前提。

把五大系统串成"一集"的样子

一集"Universe 版"视频 = 在 03 九段式基础上，叠加四个系统的"挂件"：

①Hook（载入）
②身份卡  + 显示当前【技能树】进度
③出生成长（Lv 上升）
⑤第一次选择  ← 接上集【观众投票】结果
⑦🎲【随机事件】触发
⑧【多结局】之一 + 五维评分 + 🔓解锁新技能
⑨金句 + 【投票钩子】："下一步 A 还是 B？决定下集走向"

看出来了吗：同一个身份，靠"随机事件 × 多结局 × 观众投票"，能持续产出几十集——这才是"工业化 + 可持续"的终极形态。

升级路线图（别一步到位，按这个顺序加）

阶段 1（第 1 月）：跑通基础版（00–06 章），先验证人设和流水线
阶段 2（数据稳后）：加【统一 UI 品牌】+【多结局】→ 提升完播和追更
阶段 3（有铁粉后）：上【观众互动投票】→ 建立社区护城河
阶段 4（做大）：加【技能树】+【随机事件】+【矩阵】→ 形成完整宇宙

不要在第一条视频就堆满所有系统——先让一个号能爆，再逐步加养成机制。每个阶段的目的，都是把上一阶段的流量"锁"得更深。

一句话总结 STEP 8

别人在做"人生副本"这个模板；你要做"人生副本"这个世界—— 有成长（技能树）、有意外（随机事件）、有分支（多结局）、有玩家（观众投票）、有品牌（统一 UI）。 模板会被抄烂，世界不会。

系列脚本 · 打工人《35 岁被优化的中层》（5 集追更）

这是把 实战样例 选题 #3 做成系列追更的范例——用 08 的"系列化世界观"机制，把一个选题拆成 5 集，集集留钩子，逼出"想看下一集 → 关注"。 人设沿用「职场副本·系统」，包装沿用工牌/考勤终端风（见 实战样例 第六节）。

系列设定

  • 主角：你，37 岁，某公司中层，工龄 12 年，房贷 + 二胎 + 房车皆有。
  • 主线：被优化 → 求职碰壁 → 自我重估 → 转机 → 上岸（但不是回到原点）。
  • 追更逻辑：每集是独立 60 秒短视频，但结尾留"下一集"悬念；开头用一句"上集说到……"接续，方便新观众入坑、老观众追更。
  • 发布节奏：隔日更，5 集打完一个完整弧光；数据好就给主角开"新副本"（如《37 岁转行的人》）。

EP.01 · 被优化那天

（①Hook）人生副本·职场篇，第 37 关。本关名称：被优化。开局提示——你以为最稳的一关，往往最致命。
（②身份）系统提示：你工龄 12 年，职级 P8，是同事眼里"熬出头"的人。你的负债栏写着：房贷、车贷、两个孩子。
（③成长回放）你把最好的 12 年点满在了这家公司：救过项目、带过新人、加过无数个班。你以为忠诚是一种装备。
（⑦随机事件）⚠ 随机事件触发：周一上午，HR 约你"聊一聊"。一份《协议解除》推到你面前，理由是"组织优化"。
（情绪）你没吵，签了字。走出大楼那一刻，阳光很好，你却第一次发现——这座城市，没有一个工位是真正属于你的。
（⑨钩子）系统提示：主线任务已失效，你被强制丢回"自由市场"。
下一关，比被裁更难：一个 37 岁的人，重新找工作。你觉得他几个月能上岸？评论区押一押，下集揭晓第一道坎。

EP.02 · 投出去的简历，石沉大海

（①Hook 接续）上集说到，37 岁的你被优化了。你以为凭 12 年经验，找工作不难——这一关，啪啪打脸。
（④过程）你更新了简历，投了 80 份。前 50 份，已读不回。你第一次知道，有些公司的筛选第一条是"年龄≤35"。
（⑤选择）【选择】A. 降薪求稳，什么都接；B. 死扛，只投对口的好岗位。供着房贷的你，选了 A。
（⑦事件）⚠ 你去面试一个比原来低两级的岗位，面试官比你小 8 岁，问你："你这个年纪，还能加班吗？还带得动吗？"
（情绪）回家路上你坐在车里，没有开车库的灯，坐了很久。你不是不能扛，你是第一次怀疑：是不是我真的没用了？
（⑨钩子）系统提示：你的"自信值"跌到谷底，触发隐藏剧情——"自我重估"。

EP.03 · 最难的一关：给自己重新估值

互动多结局 · 打工人《考公上岸 vs 留在大厂》

这是把 实战样例 选题 #6 做成 08 的观众投票 + 多结局范例—— 把观众从"看客"变成"编剧"，建立别人抄不走的社区护城河。人设/包装沿用「职场副本·系统」。

一、玩法机制（怎么互动）

EP.01 公共起点 → 结尾抛出 A/B 投票
        │
   评论区/点赞投票（24–48 小时）
        │
   ┌────┴────┐
 A 考公线      B 大厂线        ← 按票数最高的先更，另一条之后补更
   │            │
 各自再投票推进 → 各自 3 种结局（普通 / BAD END / 隐藏真结局）
  • 投票载体：视频结尾抛 A/B；观众在评论区扣 1/扣 2或给"代表 A/B 的两条置顶评论点赞"，点赞高的那条剧情线下集就走。
  • 衔接：下集开头固定一句"上集你们投了 ___，于是……"，让投票"真的算数"。
  • 追更钩子：每条线都留"还有隐藏结局没解锁"，逼出关注 + 二刷。

二、剧情树（全景）

EP.01《28 岁，站在考公和大厂的岔路口》  →  投票：A 考公 / B 留大厂

A·考公线
 ├─ EP.A2《辞职备考的第一年》 → 投票：A 再战 / B 放弃回职场
 │   ├─ 普通结局：二战上岸，稳定但清贫，重新理解"安稳"
 │   ├─ BAD END：三战未中，积蓄耗尽，仓促回职场
 │   └─ 隐藏真结局：备考中考清了自己要什么，转去考编/选调，找到真正适配的位置

B·大厂线
 ├─ EP.B2《留下后的第三年》 → 投票：A 卷上去 / B 躺平摸鱼搞副业
 │   ├─ 普通结局：升到主管，钱多事多，用健康换来的中产
 │   ├─ BAD END：35 岁那年遇上裁员，重演"被优化"
 │   └─ 隐藏真结局：上班练出的技能长成副业，主动离开，不再被"稳定"绑架

看出来了吗：一个选题，用"双线 × 各 3 结局"，能产出 8+ 条视频，且每条都有互动——这就是 08 说的"工业化 + 可持续"。

三、EP.01 完整脚本（公共起点）

（①Hook）人生副本·职场篇。本局是一道送命题：28 岁，你要在"考公上岸"和"留在大厂"之间，选一个。
（②身份）系统提示：你名校毕业，在大厂干了 5 年，月入 3 万，但发际线后退、班味很重、随时可能被优化。
（③现状）家里人天天打电话："别折腾了，回来考个公，稳定。"你妈已经帮你买好了 5 本行测资料。
（冲突）你算过账：大厂的钱，是用确定的健康和不确定的未来换的；公务员的稳，是用一眼望到头的人生换的。两个都对，也两个都疼。
（⑤选择·投票）【本局由你决定】
   A. 裸辞，回家全力考公，赌一个安稳。
   B. 留在大厂，继续往上爬，赌一个未来。
（⑨互动钩子）系统提示：这一局没有标准答案，只有你的选择。
评论区投票——选 A 的给"A 考公"那条置顶评论点赞，选 B 的给"B 大厂"点赞。
48 小时后，票高的那条线，我先帮你打。你会怎么选？

发布后立刻在评论区置顶两条："🅰️ 我选考公上岸（点赞这条）" 和 "🅱️ 我选留在大厂（点赞这条）"，作为投票计数器。

若 B 大厂线胜出 —— EP.B2《留下后的第三年》开头

（接续）上集你们把票投给了 B——于是你留下了，并且拼命往上爬。
（过程）3 年后你升了主管，工资翻倍，体检报告也翻了倍。你开始在凌晨的工位上问自己值不值。

六、投票运营 SOP

1. EP.01 发布即置顶 A/B 两条计数评论，引导"点赞 = 投票"。
2. 24–48h 截票，截图票数发到下集开头（"上集你们选了 X"），让投票可信。
3. 票少的那条线别浪费——隔几天补更，开头说"很多人想看另一条路，安排"。
4. 每集结尾继续投票，把"追更 + 互动"滚成习惯。
5. 把整组做成抖音合集《你选的人生·考公vs大厂》，强化"可玩"心智。

七、为什么这是最强护城河

  • UI、文案、画面都能被抄，但"和你一起投票养出来的剧情"抄不走——那是你和粉丝的共同记忆。
  • 投票天然拉爆评论率/互动率（算法最爱，见 00），还制造"必须看下集"的强追更。
  • 观众从"看客"变"玩家"，归属感 → 铁粉 → 私域和变现都更顺（见 07）。

建议上线顺序：账号稳定（有几条爆款 + 几千粉）后再上投票玩法，别在冷启动期就做（见 08 升级路线图）。
